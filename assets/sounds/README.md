# Sound effect placeholders

Place short, kid-friendly UI sound effects in this folder when they are ready.

Expected filenames used by `SoundEffectService`:

- `tap.mp3`
- `correct.mp3`
- `try_again.mp3`
- `star.mp3`
- `level_up.mp3`

These are only for brief feedback sounds. Vocabulary words and sentences must keep using `flutter_tts`, not MP3 files.
